# Kai — Daily Practice

A personal habit tracker built around the Atomic Habits framework. Mobile-first, works on any device, lives in your browser.

## Features

- **4 habit types** — Knowledge, Admin, Creativity, Wellbeing
- **Daily goal** — any 2 of 4 types per day (not a fixed pair)
- **Streak tracking** with momentum arcs
- **Tarot detail log** — full card pulls stored separately
- **Exclusions** — Marijuana tracked for awareness, never counted
- **Export / Import** — full JSON backup anytime
- All data stored locally in your browser (no server needed)

## Setup

1. Push this repo to GitHub
2. Go to **Settings → Pages → Source → main branch / root**
3. Your app is live at `https://yourusername.github.io/your-repo-name`
4. Bookmark on every device

## Adding a new habit

Open `index.html`, find the `HABITS` array, and append a new entry following the same shape. No relaunch needed — just push the change.

## Backup

Use **Settings → Export** to download a JSON snapshot. To restore on a new device, use **Import**.
